# 🐍 Python Projects and Games

Welcome to the **Python Projects and Games** repository – a collection of fun, interactive, and beginner-to-intermediate Python projects, perfect for learning, practice, or just plain enjoyment. From classic games like **Pong** and **Snake**, to simulations like **Coffee Machines** and **Rental Systems**, this repo is packed with educational and engaging content!

---

## 📦 Projects Included

| 🧩 Project Name         | 🚀 Description |
|------------------------|----------------|
| ☕ **Coffee Machine**   | Simulates a coffee vending machine. Handles payments, resources, and reports through CLI. |
| 🐢 **Crossing Turtle Game** | Help the turtle cross the road while avoiding moving cars. Increases difficulty as you level up. |
| 🔼 **Higher Lower Game** | Guess which item has more followers in a fun CLI-based comparison game. |
| 🏓 **Pong Game**        | Classic 2-player Pong game built with Turtle Graphics and Python OOP. |
| ❓ **Quiz Game**        | Trivia quiz that asks random questions and checks your score in real-time. |
| 🚗 **Rental Cars**      | Simple CLI-based car rental system with available cars and customer booking logic. |
| 🐍 **Snake Game**       | Classic Snake game with growing length, score tracking, and collision detection. |
| 🎨 **Turtle Shapes**    | Fun visual drawing using Turtle graphics — circles, polygons, and spirographs. |

## ▶️ Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/Python-Projects-and-Games.git
   cd Python-Projects-and-Games

2. **Run a Project:**

- Navigate to the project folder and run the main Python file:
  ```bash 
  cd SnakeGame
  python main.py

- Replace SnakeGame with any of the project folder names.
